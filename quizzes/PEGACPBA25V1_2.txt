1. What is a benefit of Pega low-code development?
A. The Pega low-code development tools create the code for you.
B. Developers must manually write every screen.
C. All business rules require custom Java code.
D. Low-code removes the need to define business requirements.
Answer: A
Explanation: Pega low-code development uses platform tooling to generate much of the implementation so teams can focus on the business solution.

2. Case life cycle design is a model to ______________ and _______________.
A. define a structure to create, process, and resolve work
B. define how work is completed for each specific customer request
C. define database tables and integration endpoints
D. define only the user interface of an application
Answer: A, B
Explanation: Case life cycle design provides the structure for creating, processing, and resolving work and describes how work is completed for a customer request.

3. Which of the following scenarios leverages case life cycle design?
