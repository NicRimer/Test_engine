1. What is the primary purpose of a Stage in a Pega case type?
A. To store data
B. To represent a major phase of the case
C. To control user access
D. To configure UI layouts
Answer: B
Explanation:
Stages represent high-level milestones that break the case lifecycle into business-recognizable phases.

2. What is the smallest unit of work performed in a process?
A. Step
B. Stage
C. Case
D. Data object
Answer: A
Explanation:
Steps represent individual user or system actions within a process.

3. A cancellation path that can be triggered at any time should be modeled as a:
A. Process
B. Optional action
C. Alternate stage
D. Child case
Answer: C
Explanation:
Alternate stages allow exception or interrupt flows accessible from any point.

4. A BA designs a process where a user enters data, then the system validates the information automatically. How many steps are required?
A. 1
B. 2
C. 3
D. 0
Answer: B
Explanation:
One step for user input, one automated step for validation.

5. Conditional stage transitions can be configured using:
A. Decision table
B. When conditions
C. SLAs
D. Section rules
Answer: B
Explanation:
When conditions control if/when the case moves to another stage automatically.

6. Which routing option sends work automatically to a user’s manager?
A. Route to operator
B. Route to work queue
C. Route to reporting manager
D. Route using Decision Table
Answer: C
Explanation:
Pega includes a preconfigured option to route to the operator’s reporting manager.

7. Dynamic routing to different queues based on user-selected region requires:
A. SLA escalation
B. Data transform
C. Property-based queue reference
D. Decision tree

Explanation:
Queue names can be set dynamically using property references.

8. Which rule determines who receives an assignment?
A. SLA

C. Data page

Explanation:
Routing rules are the designated mechanism for assignment distribution.

9. A BA must route work based on a risk level (High/Low). Which rule is MOST appropriate?

D. Activity

10. Work should route to a queue if the case priority exceeds 50. What should be used?

B. SLA

11. A field group list is primarily used to store:
A. A single value

C. Operator credentials
D. External API configurations

Explanation:
Field group lists store multiple structured objects of the same type (e.g., multiple addresses).

12. A single customer profile is reused in multiple case types. You should create:
A. Embedded data fields

C. A local data storage record
D. A declare expression

Explanation:
Data classes + data objects promote reuse and separation of concerns.

13. A data page with scope “Thread” means the page:
A. Is shared by everyone
B. Is unique to each user
C. Is unique per case

Explanation:
Thread scope means data is tied to a single case or thread.

14. A screen must load the latest customer data from an external service each time it opens. Which refresh strategy applies?

B. Reload once per day
C. Do not reload
D. System-managed caching
Answer: A
Explanation:
This ensures fresh data is loaded every time a user interacts with the step.

B. Data transform

Data transforms map and manipulate data in predictable ways.
